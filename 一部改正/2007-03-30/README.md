# 平成19年文部科学省告示第46号

2007年3月30日告示、4月1日施行。「特別支援学校」制度への移行に伴い、幼稚園、小学校、中学校、高等学校と特別支援学校の幼稚部・小学部中学部・高等部の7要領を更新した。

第3条から第6条は幼稚園から高等学校までの交流先などの名称を、第8条から第10条は特別支援学校の各要領の題名、対象となる障害の記述、重複障害者の定義などを変更する。改正前の名称は、過去の告示の引用などにも現れる。
