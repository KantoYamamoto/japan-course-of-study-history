# 平成14年文部科学省告示第105号

2002年5月24日告示、2003年4月1日施行。高校の第3章第6節「看護」で、系統別疾患、精神看護実習等の追加、学科による取扱いの変更などを反映した。適用される生徒の範囲は告示附則を参照。

[北海道の教育課程編成の手引（平成16年度）11ページ](https://www.koukou.hokkaido-c.ed.jp/tebiki/h16/H16sousoku.pdf)の告示本文と[文部科学省の改正後「看護」](https://www.mext.go.jp/a_menu/shotou/cs/1320647.htm)を照合した。告示どおり「分べん・産じょく」「じょく婦」を採用した。

官報は第3367号8ページ。[日本法令索引の沿革](https://hourei.ndl.go.jp/simple/detail?lawId=0000085295#history)を参照。
