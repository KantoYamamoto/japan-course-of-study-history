# 平成18年文部科学省告示第152号

2006年12月22日告示・施行。教育基本法の制定に伴う引用条番号の変更を本文に反映した。

- 中学校社会の公民的分野で、第8条を第14条に変更。
- 高等学校公民の現代社会・倫理で、第8条及び第9条を第14条及び第15条に変更。
- 高等学校公民の政治・経済で、第8条を第14条に変更。

[改正告示・新旧対照表のPDF](改正告示・新旧対照表.pdf)を収録した。PDFには、別告示の教育課程編成特例を変更する第3条も含む。
