# 平成19年文部科学省告示第146号

2007年12月25日告示。学校教育法と学校教育法施行規則の改正に伴い、既存の告示を整備した。規定の移動に関する施行日は2007年12月26日。 [文部科学省の通知](https://www.mext.go.jp/a_menu/koutou/shoumei/08020613/001.htm) ・ [官報号外第293号の目次（29–31ページ）](https://www.kanpo.go.jp/old/20071225/20071225g00293/20071225g002930000f.html)

| 告示の項目 | 対象 | 収録状況 |
| --- | --- | --- |
| 第22 | 幼稚園教育要領 | 総則の2箇所を照合し、告示冒頭の参照条番号を復元 |
| 第23 | 中学校学習指導要領 | 官報本文との照合が必要 |
| 第24 | 高等学校学習指導要領 | 官報本文との照合が必要 |
| 第25 | 特別支援学校幼稚部教育要領 | 官報本文との照合が必要 |
| 第26 | 特別支援学校小学部・中学部学習指導要領 | 官報本文との照合が必要 |
| 第27 | 特別支援学校高等部学習指導要領 | 官報本文との照合が必要 |

告示の項目は[日本法令索引](https://hourei.ndl.go.jp/simple/detail?lawId=0000112100)および各要領の沿革による。

幼稚園教育要領の1998年告示版と、文部科学省が2008年の全部改正時に作成した新旧対照表の「現行」欄を照合した。総則1の目的の参照条項は学校教育法第77条から第22条に、総則2の目標の参照条項は第78条から第23条に変わっている。 [1998年告示版](https://www.mext.go.jp/a_menu/shotou/cs/1319940.htm) ・ [文部科学省の新旧対照表3–4ページ](https://www.mext.go.jp/a_menu/shotou/new-cs/youryou/you/you2.pdf#page=3)

告示冒頭の学校教育法施行規則第76条から第38条への変更は、愛媛県の資料にある幼稚園教育要領の根拠条項の新旧対応と、2008年の全部改正告示の根拠条項から復元した。この箇所の改正文と、附則を含む告示全体は官報との照合が残っている。 [愛媛県の資料](https://www.pref.ehime.jp/uploaded/attachment/22636.pdf) ・ [2008年告示](https://erid.nier.go.jp/files/COFS/h19k/index.htm)
