# 平成19年文部科学省告示第146号

2007年12月25日告示。学校教育法と学校教育法施行規則の改正に伴い、既存の告示を整備した。施行日は2007年12月26日。文部科学省の資料に転載された附則抄録で確認した。 [附則抄録（PDFの16ページ）](https://www.mext.go.jp/content/20221017-mxt_kyokoku-000024871_4.pdf#page=16) ・ [文部科学省の通知](https://www.mext.go.jp/a_menu/koutou/shoumei/08020613/001.htm) ・ [官報号外第293号の目次（29–31ページ）](https://www.kanpo.go.jp/old/20071225/20071225g00293/20071225g002930000f.html)

| 告示の項目 | 対象 | 収録状況 |
| --- | --- | --- |
| 第22 | 幼稚園教育要領 | 総則の2箇所を照合し、告示冒頭の参照条番号を復元 |
| 第23 | 中学校学習指導要領 | 官報本文との照合が必要 |
| 第24 | 高等学校学習指導要領 | 官報本文との照合が必要 |
| 第25 | 特別支援学校幼稚部教育要領 | 総則の目的の参照条項1箇所を照合 |
| 第26 | 特別支援学校小学部・中学部学習指導要領 | 総則の教育目標にある参照条項3箇所を照合 |
| 第27 | 特別支援学校高等部学習指導要領 | 総則の教育目標にある参照条項2箇所を照合 |

第146号は中高一貫教育の特例告示2件も改正した。 [中高一貫教育の沿革](../../教育課程の特例/中高一貫教育/README.md)

告示の項目は[日本法令索引](https://hourei.ndl.go.jp/simple/detail?lawId=0000112100)および各要領の沿革による。

幼稚園教育要領の1998年告示版と、文部科学省が2008年の全部改正時に作成した新旧対照表の「現行」欄を照合した。総則1の目的の参照条項は学校教育法第77条から第22条に、総則2の目標の参照条項は第78条から第23条に変わっている。 [1998年告示版](https://www.mext.go.jp/a_menu/shotou/cs/1319940.htm) ・ [文部科学省の新旧対照表3–4ページ](https://www.mext.go.jp/a_menu/shotou/new-cs/youryou/you/you2.pdf#page=3)

告示冒頭の学校教育法施行規則第76条から第38条への変更は、愛媛県の資料にある幼稚園教育要領の根拠条項の新旧対応と、2008年の全部改正告示の根拠条項から復元した。告示冒頭を含む改正文と、附則抄録に含まれない規定は官報との照合が残っている。 [愛媛県の資料](https://www.pref.ehime.jp/uploaded/attachment/22636.pdf) ・ [2008年告示](https://erid.nier.go.jp/files/COFS/h19k/index.htm)

特別支援学校の3要領は、文部科学省が2009年の全部改正時に作成した新旧対照表の「現行」欄と照合した。幼稚部・小学部／中学部・高等部の教育の目的は第71条から第72条に、小学部の教育目標は第18条各号から第30条第1項に、中学部の教育目標は第36条各号から第46条に、高等部の教育目標は第42条各号から第51条各号に変わっている。 [幼稚部（PDFの4ページ）](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2009/09/09/1284518_2.pdf#page=4) ・ [小学部・中学部（17ページ）](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2009/09/09/1284518_2.pdf#page=17) ・ [高等部（58ページ）](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2009/09/09/1284518_2.pdf#page=58)
