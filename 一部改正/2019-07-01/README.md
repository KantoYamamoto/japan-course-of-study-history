# 令和元年文部科学省告示第18号

2019年7月1日告示・施行。平成30年告示の高等学校学習指導要領の工業・水産で、日本工業規格が日本産業規格に変わった5箇所を改正後の文部科学省版と照合し、本文に反映した。

[日本法令索引の沿革](https://hourei.ndl.go.jp/simple/detail?lawId=0000149074)と[文部科学省の改正後全文および附則抄](https://www.mext.go.jp/content/20230120-mxt_kyoiku02-100002604_03.pdf)を参照。

同じ告示による平成21年告示の改正附則への変更は、別途原典照合が必要。
