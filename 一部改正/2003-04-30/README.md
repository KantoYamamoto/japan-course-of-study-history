# 平成15年文部科学省告示第76号

2003年4月30日告示・施行。2003年4月1日以降に在籍する生徒の教育課程から適用。高校の総則第8款の4について、通信制課程の面接指導等の時間数の一部免除に、多様なメディアを利用する学習を含めた。

[文部科学省の改正後総則](https://www.mext.go.jp/a_menu/shotou/cs/1320224.htm)、[北海道の教育課程編成の手引（平成16年度）12ページ](https://www.koukou.hokkaido-c.ed.jp/tebiki/h16/H16sousoku.pdf)、[大阪教育法研究会の告示・通知の転載](https://kohoken.chobi.net/cgi-bin/folio.cgi?index=sch&query=%2Fnotice%2F20030430.txt)を照合した。

官報は第3596号5ページ。[日本法令索引の沿革](https://hourei.ndl.go.jp/simple/detail?lawId=0000085295#history)を参照。
