# 1971年1月20日の公害教育に関する一部改正

文部省は、小学校と中学校の社会科の公害に関する記述を改正した。小学校第5学年の内容(5)アは、取り上げる事例を都市に限らず、国民の健康と生活環境の両方を守ることを重視する文面になった。中学校公民的分野の「日本経済の現状と課題」では、公害の防止と国や地方公共団体の役割を明記した。

- [小学校の改正後本文](https://github.com/KantoYamamoto/japan-course-of-study-history/tree/cos-1971-01-20-partial/%E6%9C%AC%E6%96%87/%E5%B0%8F%E5%AD%A6%E6%A0%A1)。第5学年の変更後の文言は[国立教育政策研究所の掲載本文](https://erid.nier.go.jp/files/COFS/s43e/chap2-2.htm)による。改正前の段落は[国会会議録](https://kokkai.ndl.go.jp/simple/detail?minId=106515077X00419710218)と[日本環境教育学会誌の掲載例](https://www.old.jsfee.jp/EnvEdu/11_1_11.pdf#page=5)に基づく復元。引用資料によって「など／等」や言い回しに異同があり、改正前の段落は官報と未照合。
- [中学校の改正後本文](https://github.com/KantoYamamoto/japan-course-of-study-history/tree/cos-1971-01-20-partial/%E6%9C%AC%E6%96%87/%E4%B8%AD%E5%AD%A6%E6%A0%A1)。改正前は[国立教育政策研究所の掲載本文](https://erid.nier.go.jp/files/COFS/s44j/chap2-2.htm)による。改正後は[『社会科研究』の掲載本文](https://www.jstage.jst.go.jp/article/socialstudies/1983/49/1983_5/_pdf#page=4)と[国会会議録](https://kokkai.ndl.go.jp/simple/detail?minId=106515077X00419710218)を照合した。
- [改正前後の差分](https://github.com/KantoYamamoto/japan-course-of-study-history/compare/cos-1971-01-19-baseline...cos-1971-01-20-partial)。比較用の改正前コミットは、便宜上、告示前日の1月19日付とした。

日付は[昭和46年版環境白書](https://www.env.go.jp/policy/hakusyo/s46/11988.html)による。[奈良教育大学紀要](https://nara-edu.repo.nii.ac.jp/record/8288/files/NUE24_1_65-76.pdf)は文部省告示第4号としている。官報の告示原文、附則、その他の変更の有無は未照合。
