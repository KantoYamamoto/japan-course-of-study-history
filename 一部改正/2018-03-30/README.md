# 平成30年文部科学省告示第67号

2018年3月30日告示、4月1日施行。平成21年告示の高等学校学習指導要領の総則第5款の5(8)に、通級による指導、単位の認定、個別の教育支援計画・指導計画の作成などを定めた。

[全国特別支援教育推進連盟の冊子『通級による指導の新たな展開』5–6ページ](https://storage.e.jimdo.com/file/e81a096b-a240-43ed-aa26-deb4eacf458f/%E2%98%85R%E5%85%83%E7%89%88%28%E7%90%86%E8%A7%A3%E5%95%93%E7%99%BA%E5%86%8A%E5%AD%90%29%E9%80%9A%E7%B4%9A%E3%81%AB%E3%82%88%E3%82%8B%E6%8C%87%E5%B0%8E%E3%81%AE%E6%96%B0%E3%81%9F%E3%81%AA%E5%B1%95%E9%96%8B.pdf#page=4)に掲載された改正後の文言と、[新潟県の資料3](https://www.pref.niigata.lg.jp/uploaded/attachment/96920.pdf#page=4)の改正概要を照合した。本文への反映は総則第5款の5(8)まで。原告示の附則や、各教科等に関する変更の範囲と文言は官報本文との照合が必要。
