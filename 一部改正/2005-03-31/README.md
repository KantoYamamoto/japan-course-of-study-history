# 平成17年文部科学省告示第53号

2005年3月31日告示、4月1日施行。高校の総則第7款の4「大学入学資格検定合格科目の単位認定」と5「別科の科目の単位認定」を削除した。単位認定に関する規定は同日の学校教育法施行規則改正で整備された。

削除箇所は[文部科学省の通知](https://www.mext.go.jp/a_menu/shotou/kaikaku/1247222.htm)第2の2(3)で確認した。[官報号外第72号の目次](https://www.kanpo.go.jp/old/20050331/20050331g00072/20050331g000720000f.html)に掲載箇所（61ページ）がある。[日本法令索引](https://hourei.ndl.go.jp/simple/detail?lawId=0000101395)を参照。
