# 1972年10月27日の学習指導要領の一部改正

小学校・中学校・高等学校の総則が一部改正された。高等学校の第1章第1節第1款に、生徒の人間として調和のとれた育成を目ざす旨が加わったことを改正後の掲載資料で確認し、本文に反映した。

[高校総則の差分](https://github.com/KantoYamamoto/japan-course-of-study-history/compare/cos-1972-10-27...cos-1972-10-27-partial) ・ [変更を反映した高校総則](https://github.com/KantoYamamoto/japan-course-of-study-history/blob/cos-1972-10-27-partial/%E6%9C%AC%E6%96%87/%E9%AB%98%E7%AD%89%E5%AD%A6%E6%A0%A1/01-%E7%B7%8F%E5%89%87.md) ・ [国立大学協会「高等学校学習指導要領抜粋」326ページ](https://www.janu.jp/wp/wp-content/uploads/2024/01/7d818967167a279c537062d862038e3c.pdf#page=123)

同日付の文部省告示第149号は、当時の盲学校・聾学校・養護学校の小学部・中学部の要領を一部改正した。同日付で高等部に初めて作成された要領は、[告示・版の一覧](https://github.com/KantoYamamoto/japan-course-of-study-history/blob/main/告示一覧.md)から読むことができる。小学校・中学校の改正文、高校の総則のその他の変更、第149号の改正文は官報との照合が残っている。[CiNii Booksの改正後の版](https://ci.nii.ac.jp/ncid/BD09129238?l=ja) ・ [国立特別支援教育総合研究所の沿革資料](https://www.nise.go.jp/josa/kankobutsu/pub_c/c-80.pdf)

文部事務次官は同日、改正と運用について文初高第441号を出した。授業時数の弾力的な運用などを示し、『中等教育資料』第290号（1972年11月）で確認できる。[政策研究大学院大学の研究資料（115～116ページ）](https://www.grips.ac.jp/cms/wp-content/uploads/2015/05/fulltextdoc12023_1_Part11.pdf) ・ [明治学院大学の書誌出典](https://meigaku.repo.nii.ac.jp/record/2797/files/teacher_13_1-25.pdf) ・ [昭和館『文部時報』目次](https://search.showakan.go.jp/search/magazine/detail.php?material_cord=100015236)
