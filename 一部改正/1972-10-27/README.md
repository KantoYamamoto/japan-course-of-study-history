# 1972年10月27日の学習指導要領の一部改正

文部省告示第148号で小学校・中学校・高等学校の総則が一部改正された。一般方針に児童・生徒の人間として調和のとれた育成を目ざす旨が加わった。小・中・高校のそれぞれに、指導内容の重点のおき方に関する規定も追加された。

[小・中・高校総則の差分](https://github.com/KantoYamamoto/japan-course-of-study-history/compare/bdf0dc1169e64b263c3e782af31156e075c1db4d...cos-1972-10-27-no148-reviewed) ・ [高校総則の一般方針のみの差分](https://github.com/KantoYamamoto/japan-course-of-study-history/compare/cos-1972-10-27...cos-1972-10-27-partial) ・ [変更を反映した高校総則](https://github.com/KantoYamamoto/japan-course-of-study-history/blob/cos-1972-10-27-partial/%E6%9C%AC%E6%96%87/%E9%AB%98%E7%AD%89%E5%AD%A6%E6%A0%A1/01-%E7%B7%8F%E5%89%87.md) ・ [国立大学協会「高等学校学習指導要領抜粋」326ページ](https://www.janu.jp/wp/wp-content/uploads/2024/01/7d818967167a279c537062d862038e3c.pdf#page=123)・[341ページ](https://www.janu.jp/wp/wp-content/uploads/2024/01/7d818967167a279c537062d862038e3c.pdf#page=138)

小学校総則第1の1・6は[国立教育政策研究所の掲載本文](https://erid.nier.go.jp/files/COFS/s43e/chap1.htm)と[『人文研究』の改正文引用](https://www.i-repository.net/contents/osakacu/kiyo/DBd0250502.pdf)を照合した。中学校総則第1の1・7は[『発達科学研究』の改正文引用（50ページ）](https://www.mgu.ac.jp/miyagaku_cms/wp-content/uploads/2021/12/hatsurin15_08.pdf#page=4)を反映した。同誌で省略されている第7の冒頭「第２章以下に示す」と追加に伴う項番号は、小学校の改正文と中学校の改正前の本文から復元した。告示番号は[授業時数の法令規定に関する研究](https://meigaku.repo.nii.ac.jp/record/2797/files/teacher_13_1-25.pdf)でも確認できる。

同日付の文部省告示第149号は、当時の盲学校・聾学校・養護学校の小学部・中学部の要領を一部改正した。同日付の盲学校・聾学校・養護学校の高等部の要領は、[告示・版の一覧](../../告示一覧.md)から読むことができる。第148号の官報本文と附則、確認した条項以外の変更の有無、第149号の改正文は照合が残っている。[CiNii Booksの改正後の版](https://ci.nii.ac.jp/ncid/BD09129238?l=ja) ・ [国立特別支援教育総合研究所の沿革資料](https://www.nise.go.jp/josa/kankobutsu/pub_c/c-80.pdf)

文部事務次官は同日、改正と運用について文初高第441号を出した。授業時数の弾力的な運用などを示し、『中等教育資料』第290号（1972年11月）で確認できる。[政策研究大学院大学の研究資料（115～116ページ）](https://www.grips.ac.jp/cms/wp-content/uploads/2015/05/fulltextdoc12023_1_Part11.pdf) ・ [明治学院大学の書誌出典](https://meigaku.repo.nii.ac.jp/record/2797/files/teacher_13_1-25.pdf) ・ [昭和館『文部時報』目次](https://search.showakan.go.jp/search/magazine/detail.php?material_cord=100015236)
