# 学習指導要領の改訂履歴

1970年以降の学習指導要領・教育要領を、告示・校種ごとに GitHub 上でたどるための資料です。公開資料を基に再構成したアーカイブです。

- [改訂のコミット履歴](改訂履歴.md)。告示日順に本文と差分をたどる
- [告示と版の一覧](告示一覧.md)。過去の版、改正告示、未照合の改正はこちら
- [1970年の基準](1970年の基準.md)。収録開始時に適用されていた幼稚園・小・中・高校と盲・聾・養護学校の要領
- [移行措置の特例告示](移行措置/README.md)。新要領が適用されるまでの規定と改正履歴
- [義務教育学校と小中一貫教育の教育課程の特例](教育課程の特例/小中一貫教育/README.md)。義務教育学校と併設型・連携型の小・中学校に適用される規定
- [中高一貫教育の教育課程の特例](教育課程の特例/中高一貫教育/README.md)。中等教育学校などに適用される規定と改正履歴
- [通級による指導の教育課程](教育課程の特例/通級による指導/README.md)。日本語指導と障害に応じた通級指導の規定と改正履歴

## 履歴と出典

告示日を付けたコミットは公開原典から再構成したものです。時刻は日本時間の正午です。タグの前後を比較すると、同じ校種・教科の本文の変化を確認できます。

本文の出典は[国立教育政策研究所「学習指導要領データベース」](https://erid.nier.go.jp/guideline.html)および文部科学省の公開資料です。国立教育政策研究所のHTMLの段落・見出し・図表を Markdown に整形し、出典ファイルの SHA-256 を[出典台帳](出典台帳.json)に収録しています。古い版の転記表記・誤植は原典PDFや官報で確認してください。利用に当たっては[収録資料の出典と利用条件](収録資料の利用条件.md)を参照してください。
