# 学習指導要領の告示日順の履歴

1970年1月1日を起点に、学習指導要領・教育要領の制定、一部改正、移行措置と教育課程の特例を、確認できた範囲で収録しています。

`本文/` は各コミットの日付までに告示された版です。実際の適用時期は、告示の附則と移行措置に従います。1970年時点で適用されていた小・中学校の版は[1970年の基準](1970年の基準.md)から参照できます。コミットの日時は告示日の日本時間正午です。1970年1月1日は収録の基準日です。
