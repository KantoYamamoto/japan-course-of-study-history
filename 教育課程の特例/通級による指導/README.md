# 通級による指導の教育課程

日本語の能力に応じた特別の指導と、障害に応じた特別の指導について、通常の教育課程に加えられる範囲、代替できる授業、卒業に必要な単位数への算入などを定めた告示です。

- [日本語の能力に応じた特別の指導の本文（平成26年文部科学省告示第1号）](平成26年文部科学省告示第1号.md)
- [障害に応じた特別の指導の本文（平成5年文部省告示第7号）](平成5年文部省告示第7号.md)

## 告示と施行日

| 告示日 | 施行日 | 内容 | 原文・差分 |
| --- | --- | --- | --- |
| 2014-01-14 | 2014-04-01 | 小・中学校、中等教育学校の前期課程、特別支援学校の小学部・中学部で、日本語指導のために特別の教育課程を編成できるようにした。 | [平成26年文部科学省告示第1号の制定時の本文と附則](2014-01-14/平成26年文部科学省告示第1号・制定時.md) |
| 2016-03-22 | 2016-04-01 | 義務教育学校を日本語指導の対象に加えた。 | [平成28年文部科学省告示第53号の沿革](https://hourei.ndl.go.jp/simple/detail?current=-1&lawId=0000138293) ・ [本文の差分](https://github.com/KantoYamamoto/japan-course-of-study-history/compare/cos-2014-01-14-no1...cos-2016-03-22-no53-japanese) |
| 2022-03-31 | 2022-04-01（一部）、2023-04-01 | 日本語指導を高校、中等教育学校の後期課程、特別支援学校高等部にも拡大。障害に応じた通級指導では、替えられない科目の規定を更新し、日本語指導と併せて行う場合の合計の上限を定めた。 | [令和4年文部科学省告示第54号の原文PDF](2022-03-31/令和4年文部科学省告示第54号・原文.pdf) ・ [本文の差分](https://github.com/KantoYamamoto/japan-course-of-study-history/compare/cos-2022-03-31-before-no54...cos-2022-03-31-no54) |

2016年の差分は2014年の原文と2022年の対照表の改正前欄から復元しました。第53号の改め文との照合が残っています。 [文部科学省の2016年の通知（PDFの1ページ）](https://www.mext.go.jp/component/b_menu/other/__icsFiles/afieldfile/2016/03/24/1365413_14.pdf) ・ [2022年の対照表（PDFの5ページ）](https://www.mext.go.jp/content/20220328-mxt_kyokoku-000021521_02.pdf#page=5)

2022年の改正では、障害に応じた通級指導で代替できない科目等の変更が2022年4月1日に先に施行されました。日本語指導の対象校の拡大など、その他の規定は2023年4月1日施行です。 [附則（PDFの8ページ）](https://www.mext.go.jp/content/20220328-mxt_kyokoku-000021521_02.pdf#page=8) ・ [同日の学習指導要領第55号の改正](../../一部改正/2022-03-31/README.md)
