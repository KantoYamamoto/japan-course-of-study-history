# 平成30年文部科学省告示第61号

2018年3月30日告示。平成28年文部科学省告示第54号と第55号を一部改正した。 [官報号外第70号の目次（382ページ）](https://www.kanpo.go.jp/old/20180330/20180330g00070/20180330g000700000f.html)

2件の本文の第1項第1号・第2号で、対象教科等を定義する「道徳」が「特別の教科である道徳」に変わっている。小学校段階の第1号は2018年4月1日、中学校段階の第2号は2019年4月1日施行。改正後の文言と施行日は文部科学省の掲載資料を基に反映した。改正告示の官報本文は照合中。 [文部科学省「現行制度において既に認められている教育課程編成上の特例」](https://curriculumdb.mext.go.jp/bc/files/uploads/%E7%8F%BE%E8%A1%8C%E5%88%B6%E5%BA%A6%E3%81%AB%E3%81%8A%E3%81%84%E3%81%A6%E6%97%A2%E3%81%AB%E8%AA%8D%E3%82%81%E3%82%89%E3%82%8C%E3%81%A6%E3%81%84%E3%82%8B%E6%95%99%E8%82%B2%E8%AA%B2%E7%A8%8B%E7%B7%A8%E6%88%90%E4%B8%8A%E3%81%AE%E7%89%B9%E4%BE%8B.pdf)
