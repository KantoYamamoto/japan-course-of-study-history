# 義務教育学校と小中一貫教育の教育課程の特例

義務教育学校の前期課程には小学校、後期課程には中学校の学習指導要領が準用されます。2016年3月22日の告示は、小中一貫教科等を設ける場合の授業時数や指導内容の取扱いを定めています。 [制度導入時の文部科学省通知](https://www.mext.go.jp/component/b_menu/other/__icsFiles/afieldfile/2016/03/24/1365413_14.pdf)

| --- | --- | --- |
| 第54号 | 中学校連携型小学校・小学校連携型中学校 | [第54号](平成28年文部科学省告示第54号.md) |
| 第55号 | 義務教育学校・中学校併設型小学校・小学校併設型中学校 | [第55号](平成28年文部科学省告示第55号.md) |
