# 中高一貫教育の教育課程の特例

中等教育学校の前期・後期課程には、それぞれ中学校・高等学校の学習指導要領が準用されます。中等教育学校、併設型および連携型の中・高校では、中高一貫教育に応じて授業時数、学習内容を指導する学年、修得単位の扱いなどに特例があります。 [文部科学省の制度説明](https://www.mext.go.jp/a_menu/shotou/ikkan/10/1315802.htm)
