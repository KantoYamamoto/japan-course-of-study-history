# 平成20年文部科学省告示第31号

2008年3月28日告示、2012年4月1日施行。「学校教育法施行規則の一部を改正する省令の施行に伴う文部科学省関係告示の整備に関する告示」の第一・第二による中高一貫教育の特例の改正を扱います。 [日本法令索引](https://hourei.ndl.go.jp/simple/detail?lawId=0000112934) ・ [掲載号の目次（官報号外第66号・139ページ）](https://www.kanpo.go.jp/old/20080328/20080328g00066/20080328g000660000f.html)

選択教科ごとの授業時数を定めていた規定がなくなり、各教科の授業時数を減らした分を、その教科の内容を代替できる選択教科に充てる規定が、学校教育法施行規則別表第四備考第三号を参照する形になりました。 [文部科学省の中学校学習指導要領付録（PDFの130–132ページ）](https://www.mext.go.jp/a_menu/shotou/new-cs/youryou/chu/chu.pdf#page=130) ・ [国立教育政策研究所の掲載本文](https://erid.nier.go.jp/files/COFS/h19j/app.html) ・ [文部科学省の高等学校学習指導要領解説 総則編（PDFの103–104ページ）](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2010/12/28/1282000_01.pdf#page=103)
