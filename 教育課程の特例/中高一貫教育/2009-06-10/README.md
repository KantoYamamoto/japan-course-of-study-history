# 平成21年文部科学省告示第88号

2009年6月10日告示、2013年4月1日施行。中高一貫教育の特例を定める2件の第1項第2号で、学校設定科目・学校設定教科に関する科目の参照先を1999年告示の高等学校学習指導要領（第58号）から2009年告示の高等学校学習指導要領（第34号）に更新しました。 [日本法令索引](https://hourei.ndl.go.jp/simple/detail?lawId=0000117707) ・ [掲載号の目次（官報本紙第5088号・3ページ）](https://www.kanpo.go.jp/old/20090610/20090610h05088/20090610h050880000f.html) ・ [文部科学省の高等学校学習指導要領解説 総則編（PDFの103–104・108ページ）](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2010/12/28/1282000_01.pdf#page=103)
